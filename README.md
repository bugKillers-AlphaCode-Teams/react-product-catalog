# NiceGadjet - Apple Technology Store

Welcome to **NiceGadjet**, your ultimate destination for Apple technology. Our online store provides a seamless shopping experience for Apple products, including phones, tablets, and accessories. The project is built using React, TypeScript, and Vite, featuring language switching, theme customization, and a modern design.

## Technologies

- **React**: A JavaScript library for building user interfaces.
- **TypeScript**: A superset of JavaScript that adds static types.
- **Vite**: A fast build tool and development server.
- **SCSS Modules**: For modular and scoped styling.
- **LiqPay**: Integrated test form for payment processing.
- **i18next**: Internationalization framework for translating text in the application.
- **React Router**: Declarative routing for React applications.

## Features

- **Product Catalog**: Browse a wide range of Apple products including phones, tablets, and accessories.
- **Product Details**: Detailed information about each product with images, descriptions, and specifications.
- **Cart Management**: Add products to your cart, view your cart, and proceed to checkout.
- **Favorites**: Save your favorite products for easy access.
- **Language Support**: Switch between languages.
- **Theme Customization**: Toggle between light and dark themes.
- **Payment Integration**: Test LiqPay payment form for processing transactions using the following test card details:4242 4242 4242 4242

### Running the Project

1. **Clone the Repository:**

    ```bash
    git clone https://github.com/bugKillers-AlphaCode-Teams/react-product-catalog.git

    ```

2. **Navigate to the Project Directory:**
    ```bash
     cd react-product-catalog
    ```

3. **Install Dependencies:**
    ```bash
    npm install
    ```

4. **Start the Development Server:**
    ```bash
    npm run dev
    ```
5. **Open Your Browser:**
    Visit http://localhost:5173/, or another port if configured differently.
